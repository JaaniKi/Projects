# Password Puzzle

Password Puzzle is a browser-based puzzle game where your password is the challenge.
You must create a single password that satisfies an expanding list of strange and logical rules. New rules appear only after all previous ones are completed.

How to Play
* Type a password into the input field.
* Complete all visible rules.
* Each completed set of rules reveals a new one.

Winning
* You win by satisfying all rules at the same time.

Run project:
- open https://password-puzzle-game.netlify.app/
or
- go to /password-game
- run command: npm install
- run command: npm start
