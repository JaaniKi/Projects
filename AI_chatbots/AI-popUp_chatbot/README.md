# Chatbot for a website

A simple chatbot demo made for a website. For example an online store could use this.

---

## Instructions

An OpenAI API key is required to run this project.

### Set up the API key

Create a `.env` file in the root directory of the project and add the following line:

OPENAI_API_KEY=your_openai_api_key_here

## Running the Project

Navigate to the project root directory:
- cd AI-chatbot
Install dependencies:
- npm install
Start the server:
- node server.js
Open the application in a web browser:
http://localhost:3000
