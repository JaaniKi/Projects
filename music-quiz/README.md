# 🎶 Music Quiz

Realtime multiplayer music quiz game built with **Next.js** and **Socket.IO**.

Players listen to short song previews and race to guess the correct track.  
Faster correct answers earn more points.

Link to game:
## https://music-quiz-yw03.onrender.com
It might load for about 45 seconds before entering the game, because this game is deployed with a free service called Render,
as it is just a hobby project for now.

---

## Features

- Real-time audio quiz with song previews
- Multiplayer rooms with lobby & host controls
- Time-based scoring system
- Live scoreboard (updates every round)
- Responsive UI
- Docker-ready for deployment

---

## Tech Stack

- **Next.js (App Router)**
- **TypeScript**
- **Socket.IO**
- **Tailwind CSS**
- **Node.js**
- **Docker**
